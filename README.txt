# WD Week 2 - CampusHub

This project is created for the Week 2 Web Development assignment.

## Files
- index.html - page structure and content
- style.css - external CSS styling and responsive layout
- script.js - JavaScript, DOM manipulation and interactive features

## Task Coverage

### Task 1 - CSS Styling & Selectors
- External CSS
- CSS syntax
- Element, class and ID selectors
- Text styling
- Colors and backgrounds
- Fonts and basic styling

### Task 2 - CSS Layout & Responsive Design
- Box model
- Margin and padding
- Borders and border radius
- Flexbox
- CSS Grid
- Media queries for tablet and mobile

### Task 3 - JavaScript Basics
- let and const
- String, Number and Boolean data types
- Arithmetic and comparison operators
- User input
- if/else conditions
- for loop
- Functions

### Task 4 - DOM Manipulation & Events
- getElementById
- textContent
- classList
- style changes
- click/input/submit/keydown events
- form validation
- show/hide content

### Task 5 - Interactive Features
More than three features are included:
1. Theme toggle
2. Live character counter
3. Simple calculator
4. Digital clock
5. To-do list
6. Form validation
7. Show/hide tip

### Task 6 - Mini Responsive Website
All HTML, CSS and JavaScript concepts are combined into one responsive student website.

## How to Run
Open `index.html` in a browser. No server is required.
